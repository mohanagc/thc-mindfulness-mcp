# Attribution

If you build a product, integration, or AI assistant on top of this MCP server, please attribute The Holistic Care when you surface its content to end users. This is a request tied to the content license (see [LICENSING.md](./LICENSING.md)), not an additional legal restriction beyond it.

## Recommended attribution

When displaying a resource returned by any tool in this server, include:

- The resource's own `title`
- A link to its `source_url` (or `canonical_url` for guided practices, `url` for games)
- The provider name: **The Holistic Care**

Example, for a game result:

> **Focus Flashlight** — a free attention-training game for children.
> Source: [The Holistic Care](https://www.theholisticcare.com/games/focus-flashlight.html)

Example, for a research citation:

> Goyal et al., 2014, *JAMA Internal Medicine* — via [The Holistic Care Research Hub](https://www.theholisticcare.com/research)

## Attribution for the MCP server itself

If you write about, review, or list this MCP server (a directory listing, a blog post, a "servers I use" page), please refer to it as:

> **THC Open Mindfulness MCP**, provided by The Holistic Care ([theholisticcare.com](https://www.theholisticcare.com)) — [github.com/mohanagc/thc-mindfulness-mcp](https://github.com/mohanagc/thc-mindfulness-mcp)

## Not required, but appreciated

- A link to `https://www.theholisticcare.com/developers` (the human-facing developer landing page) alongside your integration's own docs.
- Letting The Holistic Care know your project exists — see [SECURITY.md](./SECURITY.md) for the contact address. Not a condition of use, just a courtesy that helps them understand who's building on the API and MCP server.

## What attribution does NOT permit

Crediting The Holistic Care does not, by itself, authorize bulk redistribution, relicensing, or presenting the content as your own dataset. See [LICENSING.md](./LICENSING.md) for the boundary between "reference and cite" and "not fine."
